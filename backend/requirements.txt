# fastapi 0.136.3 + starlette 1.3.1: the newest FastAPI that still flattens
# included routers, with the lowest Starlette that carries every published fix.
#
# The Starlette advisories against 0.35.1 (CVE-2024-47874, CVE-2025-54121,
# CVE-2026-48710, -48817, -48818, -54282, -54283, -62727) are fixed across
# 0.40.0 .. 1.3.1, and the last of them only in 1.x -- no 0.x release clears
# them, so the major bump is not optional. 1.3.1 is the floor.
#
# Why not the newest FastAPI. From 0.137 FastAPI keeps an included router as a
# single _IncludedRouter entry in app.routes instead of copying its routes up.
# Two things here walk that list and silently see nothing behind it:
#   * slowapi's SlowAPIMiddleware (_find_route_handler) finds no handler,
#     treats the request as exempt, and the global default limit stops
#     applying to every undecorated route: six calls under 3/minute, six 200s
#     (tests/test_rate_limits_actually_apply.py).
#   * the public-surface tests (test_route_access.py,
#     test_secure_upgrades_phase3.py), which read the route table to prove
#     exactly what is reachable.
# 0.136.3 has no upper bound on Starlette (>=0.46.0) and still flattens, so all
# of the above pass unchanged. Going past 0.136 means replacing slowapi's route
# lookup first; test_rate_limits_actually_apply.py is the tripwire.
#
# Starlette has its own pin because FastAPI does not cap it: left to the
# resolver it would float to whatever is newest.

# Transitive dependencies, pinned here only because the version the resolver
# picks on its own carries an advisory. Nothing in this app imports them
# directly; they arrive via requests/botocore/sentry-sdk (urllib3), alembic
# (Mako), and aiohttp/yarl (multidict). Pinning a transitive dependency is a
# cost -- it has to be revisited by hand when the parent moves -- so each one
# states what it is for, and each is the lowest version that carries the fix
# rather than the newest on the index.
#
# urllib3 2.8.0: CVE-2026-97687 (HTTPS-proxy TLS settings ignored),
#   CVE-2026-97689 (unbounded chunk-size line buffered from a chunked
#   response), CVE-2026-97688 (infinite loop on chunked deflate). 1.26.0
#   through 2.7.0 are affected. This is the one of the three that is reachable
#   in anger: sentry-sdk and boto3 talk to hosts over the network.
# Mako 1.4.3: CVE-2026-102991, TemplateLookup path traversal via a Windows
#   drive letter. Not exploitable here -- alembic renders its own migration
#   templates on Linux and no URI is resident-supplied -- but the pin is free
#   and leaving a known-bad version in the tree costs a reader the same
#   investigation every time the report runs.
# multidict 6.9.1: CVE-2026-104874, a reference leak in the C extension's
#   items-view union/subtraction that a remote caller can drive into unbounded
#   memory growth. 6.7.0 through 6.9.0 are affected. 7.x also carries the fix
#   but aiohttp 3.14.5 requires multidict<7.0, so 6.9.1 is the version that
#   actually resolves.
urllib3==2.8.0
Mako==1.4.3
multidict==6.9.1
